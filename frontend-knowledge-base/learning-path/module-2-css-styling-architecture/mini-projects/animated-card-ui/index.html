Animated Progress Cards

Progress bars animate using transform: scaleX() with transform-origin: left — no layout properties. Each card entrance uses a staggered animation-delay. The bar width is passed as --bar-width via inline style.

Scroll-Driven Reveal

Cards animate as they enter the viewport using the modern animation-timeline: view() CSS API. A @supports guard keeps it opt-in, and IntersectionObserver in script.js provides a fallback for older browsers.
