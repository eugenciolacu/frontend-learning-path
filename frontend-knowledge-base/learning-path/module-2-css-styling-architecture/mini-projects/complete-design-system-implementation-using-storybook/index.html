Scroll-Reveal (js-reveal)Ch. 10 · scroll-driven, IntersectionObserver
ℹ

How it works

Elements with .js-reveal start at opacity: 0. When they enter the viewport, script.js adds .is-revealed which transitions them in. Browsers supporting animation-timeline: view() use native scroll-driven animation instead.
