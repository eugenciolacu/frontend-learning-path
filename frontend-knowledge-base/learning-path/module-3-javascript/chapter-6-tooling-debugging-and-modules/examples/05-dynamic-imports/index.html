Dynamic Imports Demo

Dynamic import() loads modules on demand (lazily) instead of at startup. This improves initial page load time by only loading code when it is actually needed.

Note: Serve this folder over HTTP to use ES Modules. Use npx serve . or VS Code's Live Server extension. Watch the Network tab in DevTools to see modules load on demand.

Scenario 1: Load a Feature on Button Click

The heavy-chart.js module is NOT loaded at startup. It is only fetched from the server when you click the button. Check the Network tab — the file won't appear until you click.

Watch DevTools → Network tab for the request to heavy-chart.js

Chart will render here after loading...

Scenario 2: Conditional Module Loading

Select a theme. The corresponding theme module is loaded on demand. Each theme is a separate module file — only the selected one loads.

Select a theme and click Apply...

Scenario 3: Simulated Routing (Code Splitting)

Each "page" is a separate module. Only the current page's module is loaded. This is the pattern used by React Router, Vue Router, etc.

Click a page to load it...

Scenario 4: Using import() with Promise.then()

Dynamic import() returns a Promise, so you can use .then() instead of await.
