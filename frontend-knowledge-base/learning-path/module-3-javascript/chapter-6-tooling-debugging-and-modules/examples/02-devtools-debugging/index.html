Debugging with Browser DevTools

This example demonstrates practical debugging scenarios. Open DevTools → Sources and set breakpoints in debugging-demo.js to pause execution and inspect state.

Scenario 1: Shopping Cart Total Bug

The cart total calculation has a bug. Set a breakpoint in calculateTotal() to find it.

Scenario 2: Using the debugger Statement

Click the button below. If DevTools is open, execution will pause inside the loop at the debugger line. Inspect i and sum in the Scope panel.

Scenario 3: Async / Fetch Debugging

Simulates a failed API call. Open the Network tab to see the request, and the Console to see the error.

Scenario 4: Measuring Performance

Uses console.time() and the Performance API to measure how long sorting 500,000 items takes.

Tip: Open DevTools → Sources, navigate to debugging-demo.js, and click on any line number to set a breakpoint before clicking the buttons.
