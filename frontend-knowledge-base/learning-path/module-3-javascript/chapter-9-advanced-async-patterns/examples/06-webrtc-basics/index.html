WebRTC Basics

Chapter 9 · Advanced Asynchronous Patterns

What This Example Demonstrates

  • Capturing local camera & microphone with getUserMedia()
  • Creating an RTCPeerConnection (caller & callee — same page)
  • The Offer/Answer/ICE candidate exchange (signalling simulation)
  • RTCDataChannel — peer-to-peer text messaging
  • Adding and receiving media tracks
  • Connection state monitoring via connectionState events
Note: This demo runs both Caller and Callee in the same browser tab (a "loopback" peer connection). In a real app the signalling messages (offer, answer, ICE candidates) would travel through a WebSocket server between two different users. The WebRTC logic is identical either way.
