Caching Strategies (Reference)

Cache First Serve from cache; fall back to network. Best for static assets.
Network First Try network; use cache if offline. Best for dynamic data.
Stale-While-Revalidate Serve cache instantly; update in background. Best for avatars/feeds.
Cache Only Always from cache. For fully-offline apps or pre-cached bundles.
