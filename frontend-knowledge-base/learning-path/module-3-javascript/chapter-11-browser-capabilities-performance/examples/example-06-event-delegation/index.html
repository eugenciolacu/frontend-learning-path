Event Delegation Demo

A fully interactive todo app built with a single delegated event listener. No matter how many items are added, only one listener handles all clicks.

Why Event Delegation?

❌ Without Delegation

  • N listeners for N items
  • Memory grows with list
  • Dynamic items not covered
  • Must re-bind after DOM update

✅ With Delegation

  • 1 listener handles all items
  • Constant memory usage
  • New items work automatically
  • Scales to thousands of items

Todo App (Single Listener)

All button clicks (Complete, Edit, Delete) and filter tab clicks are handled by one event listener on the list container, using event.target.closest() to identify the action.
