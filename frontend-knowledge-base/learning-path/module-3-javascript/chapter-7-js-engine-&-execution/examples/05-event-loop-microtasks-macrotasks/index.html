Microtasks vs Macrotasks — Quick Reference

        

          
            

              
              Microtasks
              Macrotasks
            

          
          
            

              Examples
              Promise.then/catch/finally, queueMicrotask(), MutationObserver
              setTimeout, setInterval, setImmediate, I/O, UI events
            

            

              Priority
              Higher
              Lower
            

            

              How many per cycle?
              ALL — entire queue drained
              ONE per event loop cycle
            

            

              Runs before render?
              Yes
              No (macrotask → render → next macrotask)
            

            

              Risk
              Infinite microtasks = starvation
              Long macrotasks block UI
