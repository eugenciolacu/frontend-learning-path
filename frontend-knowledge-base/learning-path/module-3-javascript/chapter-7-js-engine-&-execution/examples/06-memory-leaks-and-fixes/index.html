Memory Management & Memory Leaks

Learn the JavaScript garbage collection model and how to identify and fix the most common memory leaks.

How Garbage Collection Works

🌱
GC Roots
window, current stack, registers
→
🔍
Mark Phase
Traverse all reachable object references. Mark as "alive".
→
🗑️
Sweep Phase
Free all memory NOT marked as reachable.
✅ Reachable (stays in memory): let obj = { name: "Alice" }; — 'obj' variable references the heap object → reachable
❌ Unreachable (eligible for GC): obj = null; — reference removed → object cannot be reached from roots → freed

Common Memory Leaks

01

Accidental Global Variables

❌ Leaks
function createLeak() {
  // Missing let/const/var!
  leakyVar = "I am global now";
}
createLeak();
// leakyVar is on window forever
✅ Fixed
function noLeak() {
  const localVar = "properly scoped";
  // Also: use "use strict" to catch
  // accidental globals as errors
}
noLeak();
02

Forgotten Event Listeners

❌ Leaks
const btn = document.querySelector("button");
const handler = () => doWork();

btn.addEventListener("click", handler);

// Remove button from DOM but DON'T
// remove listener → listener + its
// closure scope stays in memory!
btn.remove();
✅ Fixed
const btn = document.querySelector("button");
const handler = () => doWork();

btn.addEventListener("click", handler);

// Remove listener BEFORE removing element
btn.removeEventListener("click", handler);
btn.remove();

// Or use AbortController:
const ac = new AbortController();
btn.addEventListener("click", handler,
  { signal: ac.signal });
ac.abort(); // removes all at once
Listener calls: 0
03

Closures Holding Large Scopes

❌ Leaks
function createLeak() {
  // 1 million items allocated
  const largeData = new Array(1_000_000)
    .fill("data");

  // inner only uses largeData[0],
  // but holds reference to ALL of it!
  return function inner() {
    return largeData[0];
  };
}

const query = createLeak();
// largeData (1M items) is never freed
// as long as 'query' exists!
✅ Fixed
function createFixed() {
  const largeData = new Array(1_000_000)
    .fill("data");

  // Extract only what you need
  const firstItem = largeData[0];
  // largeData can now be GC'd after
  // createFixed() returns!

  return function inner() {
    return firstItem; // only a string
  };
}

const query = createFixed();
04

Timers Not Cleared

❌ Leaks
function startComponent() {
  const heavyData = new Array(100_000)
    .fill("payload");

  // This interval runs forever!
  // heavyData is held by the closure
  setInterval(() => {
    process(heavyData);
  }, 1000);
  // No way to stop it or free memory
}
✅ Fixed
function startComponent() {
  const heavyData = new Array(100_000)
    .fill("payload");

  const id = setInterval(() => {
    process(heavyData);
  }, 1000);

  // Return cleanup function
  return function cleanup() {
    clearInterval(id); // ✅
    // heavyData can now be GC'd
  };
}

const stop = startComponent();
// When done:
stop();
05

Detached DOM Nodes

❌ Leaks
let savedRef;

function createAndSave() {
  const div = document.createElement("div");
  document.body.appendChild(div);
  savedRef = div; // hold a reference

  // Remove from DOM...
  div.remove();
  // ...but 'savedRef' still points to it!
  // Div is detached — not in DOM,
  // but not GC'd either. Memory leak!
}
✅ Fixed
let savedRef;

function createAndSave() {
  const div = document.createElement("div");
  document.body.appendChild(div);
  savedRef = div;

  div.remove();

  // Nullify the reference — now GC can
  // collect the detached DOM node
  savedRef = null; // ✅
}

// Or use WeakRef to not prevent GC:
const weakRef = new WeakRef(div);
const el = weakRef.deref(); // may be undefined
06

Unbounded Cache / Map

❌ Leaks
const cache = new Map();

function processUser(user) {
  if (!cache.has(user.id)) {
    cache.set(user.id, expensiveOp(user));
  }
  return cache.get(user.id);
}
// Map grows forever, no eviction policy!
// Even if 'user' objects are gone,
// cache holds them alive by user.id key
✅ Fixed
// Option 1: WeakMap — GC-friendly
// (keys must be objects; auto-evicted)
const weakCache = new WeakMap();

function processUser(user) {
  if (!weakCache.has(user)) {
    weakCache.set(user, expensiveOp(user));
  }
  return weakCache.get(user);
}
// When 'user' object has no other refs,
// WeakMap entry is automatically GC'd ✅

// Option 2: LRU Cache with size limit
// (evicts oldest entries when full)

Detecting Memory Leaks with DevTools

📸 Heap Snapshot

DevTools → Memory → Take Snapshot. Compare two snapshots before and after a suspected leak. Look for objects that grow between snapshots.

📈 Allocation Timeline

DevTools → Memory → Allocation instrumentation on timeline. Records allocations over time — helps find what's being allocated and never freed.

📊 Performance Monitor

DevTools → More Tools → Performance Monitor. Watch JS Heap Size in real time. A heap that only grows and never shrinks indicates a leak.

🔍 Node.js: process.memoryUsage()
console.log(process.memoryUsage());
// { rss, heapTotal, heapUsed, external }
